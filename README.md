# Security Lab

A Flask web application for learning, testing, and practicing web security in a controlled environment.

## 🚀 Live Demo

[Open Security Lab](https://sherullah.pythonanywhere.com/)

## Features

- User registration
- User login/logout
- Posts
- Comments
- Feedback
- Flask + SQLAlchemy
- SQLite database
- Deployed on PythonAnywhere

## ⚠️ Disclaimer

This project is built for educational purposes, security testing, and training.
Only test security techniques against systems you own or have explicit permission to test.
